# Raye's Smolslime case edits

This is a pack of [smolslime](https://docs.slimevr.dev/smol-slimes/index.html) case stls I've made based on [LyallUlric's original stackedsmol case design](https://www.thingiverse.com/thing:6941615) and the [ibis trackers by brisfknibis](https://github.com/brisfknibis/ibis-trackers).

I was originally inspired by the hook system made by Lyall but wanted to 
<ol type="a">
  <li>Improve upon the hook itself and make it easier to print and stronger</li>
  <li>Make the tray case itself more versatile, so that it could be used in the standard way and allow people to just feed through the strap through the tray case and use a fastener and hook as the hook system instead</li>
  <li>Make the case support other strap lengths. I personally use 38mm and 25mm straps, based on the original slimevr strap widths</li>
  <li>Do the same with ibis trackers.</li>
</ol>
